# RenéeKing.co

A small, responsive media page for the RenéeKing.co music and therapeutic bodywork project.

## Preview

Open `index.html` in a modern browser, or serve this folder with any static web server. The page includes collapsible sections, a browser-local audio player that accepts multiple audio files, and embed slots for YouTube, Facebook video, and Apple Music.

## Audio and media notes

- Audio files selected in the MP3 player are played locally in the current browser session. They are not uploaded or saved. To publish tracks to visitors, put the audio files on a hosting service and add persistent URLs/storage and upload handling.
- YouTube, Facebook, and Apple Music embeds require public links and may be restricted by each provider's privacy, availability, account, or embed settings.
- The page is static and does not include a backend, file storage, user authentication, or an Android/Google Play build configuration.

## Google Play

This repository currently contains a static website only. Publishing an Android app requires an Android project (for example, a configured Android Studio/Gradle app), signing credentials, store listing assets, and Google Play Console setup. None of those are present in this repository.
